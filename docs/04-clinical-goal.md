# 임상 대시보드 목표 — 가능한 것과 불가능한 것

2026-08-03 확정된 프로젝트 목표: **EEG만 사용**, 4-class 분류, 최종 산출물은 **의사가 보는 임상 대시보드**.
딥러닝 대신 머신러닝을 택한 것은 배포·해석가능성 때문.

---

## 1. EEG만으로 수면 질환을 잡을 수 있는가 — 질환마다 다르다

| 질환 | EEG만으로 가능한가 | 이유 |
|---|---|---|
| **기면증 (narcolepsy)** | **상당 부분 가능** | REM 잠복기 단축, 입면기 REM(SOREMP)이 핵심 소견. 둘 다 hypnogram에서 직접 나온다 |
| **불면증** | **지표는 전부 나온다** | 입면잠복기·수면효율·WASO가 전부 hypnogram 파생. 단 진단 자체는 주관적 호소 기반이라 PSG로 확정하지 않는다 |
| **수면무호흡 (OSA)** | **진단 불가, 스크리닝만** | 진단 기준 AHI가 기류·산소포화도로 정의된다. EEG로는 원리적으로 셀 수 없다. 다만 무호흡이 일으키는 각성·수면분절은 EEG에 보인다 |
| **RBD** | **약함** | REM 중 근긴장 소실(atonia)이 진단 기준 → 턱 EMG 필수 |
| **주기성사지운동 (PLM)** | **불가** | 정강이 EMG 필요. EEG로는 동반 각성만 보임 |

**정리**: 가장 흔한 질환(무호흡)이 하필 EEG로 가장 안 되는 쪽이다.
반대로 기면증과 불면증 지표는 EEG와 궁합이 좋다.

→ **"EEG로 질병을 진단한다"가 아니라 "EEG만으로 수면 구조를 정량화해 의사에게 보여준다"로 잡아야 한다.**
이건 물러서는 게 아니라 정확한 포지셔닝이다. 의사가 PSG 리포트에서 실제로 읽는 게 수면 구조 지표다.

---

## 1-1. 역할 분담 — 모델은 질병을 판단하지 않는다

**만드는 것은 수면 단계 분류 모델 하나다.** 질병 판단은 의사가 한다.

```
EEG  →  [수면 단계 분류 모델]  →  hypnogram  →  임상 지표(§5)  →  의사가 판단
                                                      ↑
                                          질병별 양상은 여기에 "해석 참고"로 표시
                                          (문헌 지식이지 학습 대상이 아니다)
```

따라서 **질병 라벨이 붙은 데이터가 필요 없다.** §1의 표는 "EEG로 무엇을 못 잡는가"를 알기 위한 것이지
질병 분류기를 만들기 위한 게 아니다.

질병별 양상(예: 기면증에서 REM 잠복기 단축)은 **대시보드에 주석으로 붙이는 도메인 지식**이다.
지표 옆에 "정상 범위"와 "이 값이 낮으면 무엇을 시사하는지"를 표시해 주면 된다.
이건 모델 학습이 아니라 UI·문헌 정리 작업이다.

## 2. 가진 데이터로 충분하다 — 다만 한계는 알고 가자

### HMC — 수면 단계 라벨만 있다 (그리고 그거면 된다)

151개 `*_sleepscoring.txt` 전체의 주석을 전수 열거한 결과:

| 주석 | 개수 |
|---|---:|
| Sleep stage N2 | 50,083 |
| Sleep stage N3 | 26,671 |
| Sleep stage W | 23,686 |
| Sleep stage R | 21,255 |
| Sleep stage N1 | 15,548 |
| Lights on | 151 |
| Lights off | 151 |

**무호흡 이벤트도, 각성(arousal)도, 사지운동도, 진단명도 없다.**
피험자 정보도 집계값뿐이다(남 85/여 66, 연령 53.9±15.4, AHI 14.6). **개인별 진단·나이·성별 없음.**

### EDFX — 건강한 성인이라 질병 자체가 없다

→ **수면 단계 분류 모델을 만드는 데는 이걸로 충분하다.** 필요한 건 EEG와 단계 라벨뿐이다.

두 데이터셋을 합치면 **피험자 229명(EDFX 78 + HMC 151)** 이고, 건강인과 환자가 모두 들어간다.
임상 배포를 목표로 한다면 환자 코호트(HMC)가 포함된 게 오히려 중요하다 —
건강인 데이터로만 학습한 모델이 환자에게 잘 듣는다는 보장이 없기 때문이다.

## 3. (참고) 나중에 질병별 검증이 필요해지면 — CAP Sleep Database

[PhysioNet capslpdb 1.0.0](https://physionet.org/content/capslpdb/1.0.0/) · **무료 공개** (Open Data Commons Attribution License)

이탈리아 파르마 Ospedale Maggiore 수면장애센터, **108개 녹음, 질병 라벨 있음**.

| 분류 | 녹음 수 |
|---|---:|
| 야간전두엽뇌전증 (NFLE) | 40 |
| REM수면행동장애 (RBD) | 22 |
| **건강 대조군** | **16** |
| 주기성사지운동 (PLM) | 10 |
| 불면증 | 9 |
| 기면증 | 5 |
| 수면호흡장애 (SDB) | 4 |
| 이갈이 | 2 |

- 채널: EEG 10-20 (F3/F4, C3/C4, O1/O2 — A1/A2 기준) + EOG + 턱·정강이 EMG + 기류 + 호흡노력 + SaO2 + ECG
- 채점: **R&K** — EDFX와 같으므로 우리 4-class 매핑이 그대로 적용된다

**주의할 점**
- **질병별 표본이 너무 작다.** 기면증 5, SDB 4, 이갈이 2로는 분류기를 만들 수 없다.
- 가장 큰 집단인 NFLE 40은 엄밀히 뇌전증이지 일반적인 수면질환 대시보드의 주 타깃이 아니다.
- 단일 기관 데이터다.
- 현실적으로 가능한 건 **"건강 16 vs 질환군"의 군간 수면구조 차이 기술**이지 개별 질병 분류가 아니다.

## 4. 머신러닝 선택은 옳다 — 다만 더 강한 근거가 있다

형님이 든 이유(배포·해석가능성)에 더해, 결정적인 게 하나 더 있다.

**라이선스.** Phan 계보 딥러닝 모델(SeqSleepNet, XSleepNet, SleepTransformer, L-SeqSleepNet)은 **전부 CC-BY-NC**다.
비상업 조건이라 **병원 제품에 못 쓴다.** 반면 YASA는 BSD-3-Clause라 상업 이용이 가능하다.
대시보드가 최종 목표라면 이건 성능 논쟁보다 우선한다.

부수적으로:
- 부스팅 트리는 CPU에서 밀리초 단위로 돈다. 병원에 GPU가 없어도 된다.
- 해석 가능한 모델이 의료기기 인허가에 유리하다.
- 성능도 안 밀린다 (Van der Donckt 2023: 피험자 단위 CV에서 DeepSleepNet 상회).

**단, 솔직히 짚을 것**: 대시보드에서 의사가 보는 건 hypnogram과 파생 지표지 모델 내부가 아니다.
해석가능성은 "이 단계 판정을 믿어도 되나"를 답하는 데 쓰이지, 임상 판단 자체를 대체하지 않는다.
모델 신뢰도(예측 확률 기반 confidence)를 지표로 함께 보여주는 쪽이 실질적이다.
YASA 논문의 근거: 확신도 80% 이상 에포크는 정확도 95.9%, 미만은 62.9%다.

## 5. 대시보드가 실제로 보여줘야 할 것

hypnogram만 있으면 아래가 전부 계산된다. 의사가 PSG 리포트에서 읽는 표준 지표다.

| 지표 | 의미 | 관련 질환 |
|---|---|---|
| TST (총 수면시간) | 실제로 잔 시간 | 전반 |
| SE (수면효율) | TST / 침상시간 | 불면증 |
| SOL (입면잠복기) | 눕고 잠들기까지 | 불면증 |
| WASO | 입면 후 각성시간 합 | 불면증, 무호흡 |
| **REM 잠복기** | 입면부터 첫 REM까지 | **기면증** (짧아짐) |
| 단계별 비율 (%W/LS/DS/R) | 수면 구조 | 전반 |
| 수면 분절 지수 | 단계 전환 빈도 | 무호흡 (증가) |
| 수면 주기 수·구조 | 90분 주기가 정상적인가 | 전반 |

**참고 정상치** (HMC 집계값, 수면클리닉 환자 151명): TIB 7.6h, TST 6.3h, SE 83%.

## 6. EEG-only의 진짜 강점 — 웨어러블

채널이 적은 게 단점만은 아니다. **EEG 1~2채널이면 헤드밴드·가정용 기기로 측정 가능하다.**
병원 PSG는 하룻밤에 비싸고 대기가 길며 한 번밖에 못 잰다.

→ **"집에서 여러 밤 재서 수면 구조의 추이를 본다"**는 건 병원 PSG가 구조적으로 못 하는 것이다.
논문 각도로도, 제품 각도로도 이쪽이 "PSG를 EEG로 흉내낸다"보다 훨씬 강하다.

## 7. 제안하는 진행 순서

1. **4-class EEG-only 분류 모델** — 정직한 프로토콜로 EDFX + HMC. **이게 프로젝트의 본체다.**
2. **hypnogram → 임상 지표 자동 산출** — §5의 표. 모델만 되면 순수 계산으로 나온다.
3. **대시보드** — §5 지표 + 에포크별 신뢰도 + 지표별 해석 참고(정상범위, 시사점).

질병 라벨 데이터는 이 경로에 필요 없다. CAP(§3)은 나중에 "우리 모델이 질환군에서도 버티는가"를
검증하고 싶어질 때의 선택지로 남겨 둔다.

### 모델 품질이 전부다
대시보드의 모든 지표가 hypnogram에서 파생되므로, **단계 분류가 틀리면 지표가 전부 틀린다.**
특히 REM 잠복기·수면효율은 몇 개 에포크 오분류에 민감하다.
따라서 여기서 정직한 평가 프로토콜을 지키는 것이 학술적 정확성 문제가 아니라 제품 신뢰성 문제다.
