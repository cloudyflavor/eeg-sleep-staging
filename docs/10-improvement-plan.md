# 성능 개선 계획

목표는 macro-F1 을 3%p 이상 올리는 것이다. 분석은 그 자체가 목적이 아니라
어디를 건드려야 3%p 가 나오는지 찾는 수단이다.

"지금까지 안 것" 의 수치는 밴드파워 적분을 고치기 전, 기준선 0.838 일 때 잰 것이다.
날짜가 붙은 절은 고친 뒤 우승 조합 0.844 에서 다시 잰 것이다.

**진척: +0.62 %p.** 특징 추가로 0.8381 에서 0.8443 이 됐다. 자세한 것은
`09-analysis.md` 참고.

## 지금까지 안 것

### 클래스별 성적과 남은 여지

| 단계 | F1 | 만점까지 |
|---|---:|---:|
| W | 0.925 | 7.5%p |
| LS | 0.873 | 12.7%p |
| DS | 0.805 | 19.5%p |
| R | 0.753 | 24.7%p |

macro-F1 은 네 값의 평균이다. **3%p 를 올리려면 네 개를 합쳐 12%p 를 벌어야 한다.**
R 하나만 0.873 까지 올려도 목표가 채워진다. 여지가 가장 큰 곳은 R 과 DS 다.

### 틀린 것이 어디로 가나

```
R  → LS   26.7%
DS → LS   21.2%
W  → LS    6.0%
LS → W     4.9%
```

전부 LS 로 샌다. LS 가 전체의 46% 라 애매하면 그쪽으로 쏠린다.

### R 과 DS 는 실패 이유가 다르다

구간 가장자리에서 몇 칸 안쪽인지에 따른 정확도.

```
가장자리에서   W      LS     DS     R
0칸          0.661  0.713  0.559  0.470
4칸          0.918  0.893  0.862  0.715
8칸          0.958  0.927  0.927  0.760
```

**DS 는 안쪽으로 가면 회복하고 R 은 멈춘다.**

원본 라벨에서 잰 구간 길이.

```
        구간 수   중앙값   1칸 비율   3칸 이하 구간에 있는 에포크 비율
W       3,693      2      38.4%    5.4%
LS      7,081      4      27.8%    6.1%
DS      2,663      1      53.3%   21.9%
R       1,560     10       9.5%    2.7%
```

DS 는 절반 이상이 30초 한 칸이다. DS 오답의 절반이 3칸 이하 구간에서 나온다.
R 은 구간이 가장 긴데도 못 맞힌다.

### R 은 확신하며 틀린다

```
REM 확신도 중앙값   맞힘 0.886   틀림 0.713
틀린 REM 중 확신도 0.8 초과   34.8%
```

헷갈려서 찍는 것이 아니라 특징이 그 구간을 LS 처럼 보이게 만들고 있다.
REM 판독은 원래 안구운동과 턱 근전도를 같이 보는데 우리는 그 두 채널이 없다.

### 사람마다 크게 다르다

```
78명 macro-F1   평균 0.789   표준편차 0.109   최저 0.389   최고 0.948
하위권 DS 비율 0.2~2%,  상위권 10~15%
```

전체를 한 덩어리로 재면 0.839 인데 한 사람씩 재서 평균 내면 0.789 다.

## 갈린 것 (2026-08-31)

**하위권은 진짜 못 읽는다.** kappa 로 재도 0.891 에서 0.663 으로 같이 떨어지고,
단계가 세 개뿐인 녹음이 오히려 점수가 높다. macro-F1 탓이 아니다.
근거와 수치는 `09-analysis.md` 참고.

**범인은 나이다.** 녹음별 macro-F1 과 나이의 순위상관이 −0.51 이고, 80세 초과는
0.711 인데 40세 미만은 0.868 이다. 통로는 DS 비율이다. 14.2 %에서 2.7 %로 줄어든다.

**진짜 병목은 고령의 REM 이다.** 80세 초과에서 REM 의 33.7 %가 LS 로 새고
REM 확률 중앙값이 0.645 다. 40세 미만은 90.8 %를 맞히고 중앙값이 0.967 이다.

## 개선 후보와 예상

싼 것부터. 앞의 셋은 모델을 다시 학습하지 않는다.

### 1. 상태 전이 후처리 — 남은 후보 중 가장 유망

수면 단계는 아무렇게나 바뀌지 않는다. 각성에서 깊은 잠으로 바로 뛰지 않는다.
모델이 조각마다 낸 확률에 **단계 사이 전이 확률**을 곱해 가장 그럴듯한 경로를 고른다.

실측 근거가 셋 있다.

- **틀린 조각의 87.1 %는 정답이 2등이었다.** 정보가 없어서 틀린 것이 아니라
  마지막에 하나 고르는 방식이 틀린 것이다
- **오답의 11.8 %가 앞뒤와 다른 한 칸짜리다.** 경로로 판단하면 직접 겨냥할 수 있다
- **W 에서 DS 로 바로 가는 전이가 0.00 %다.** 지금은 이 규칙을 전혀 모른다

전이 표는 **라벨만으로** 만든다. 모델이 안 끼어들므로 평가 대상을 뺀 나머지 사람의
정답만 세면 되고, 2·3번과 달리 학습을 다시 돌릴 필요가 없다.

**실시간에서도 쓸 수 있다.** 뒤를 얼마나 볼지 고를 수 있고, 우리는 이미 9조각을
기다리므로 그 안에서 뒤를 보는 것은 지연을 늘리지 않는다. 밤 전체를 보는 방식은
상한선을 재는 용도로만 쓰고 따로 표기한다.

예상 1~3 %p. 비용 낮음.

### 2. 클래스별 임계값 조정 — 접는다 (2026-08-31)

녹음마다 macro-F1 이 가장 높아지는 DS 문턱을 **정답을 보고** 골라 상한선을 쟀다.
전체 +0.87 %p, 70세 이상 +1.36 %p 다.

**도달 가능한 최대치가 1 %p 도 안 된다.** 정직하게 학습 묶음에서만 정하면 더 낮고,
게다가 저장해 둔 예측은 각 조각이 평가 대상이었을 때의 것뿐이라 문턱을 정직하게
정하려면 학습을 10번 더 돌려야 한다. 값어치가 없다.

### 3. 확률 보정 — 값어치가 작다 (2026-08-31)

부스팅이 내는 확률이 실제 빈도와 얼마나 어긋나는지 쟀다.

```
0.7 이라고 말할 때   실제 정답률 91.6 %
0.9 이라고 말할 때   실제 정답률 96.0 %
```

오히려 자기를 낮춰 말한다. 크게 어긋나 있지 않아 보정해서 벌 것이 적다.
2번과 같은 이유로 정직하게 맞추려면 학습을 다시 돌려야 한다.

### 4. REM 전용 특징

이마 전극은 눈 바로 위에 있어 안구운동 전위가 섞여 들어온다. 뒤통수에는 거의 안 섞인다.
그 차이를 특징으로 만들면 EOG 없이도 REM 단서를 얻을 수 있다.

- 0.3~1Hz 대역에서 앞뒤 채널 비대칭
- 저주파 성분의 급변 횟수
- 두 채널의 저주파 상관

싼 확인이 먼저 있다. 지금 `ratio__delta_front_back` 이 이미 있으니
**변수 중요도에서 몇 위인지** 보면 이 방향에 힘이 있는지 알 수 있다.

예상 1~4%p. 비용 중간. R 의 여지가 24.7%p 로 가장 크다.

### 5. 피험자 요인과 나이 — 접는다 (2026-09-01)

**넣어 봤고 안 통했다.** age 는 +0.05 %p 로 10 fold 중 5개, age+sex 는 +0.09 %p 로
5개다. 동전 던지기다. 게다가 나이는 458개 특징 중 중요도 1위인데 성능은 안 오른다.
뇌파 특징이 이미 나이 정보를 갖고 있어서 새 정보가 아니라 지름길이기 때문이다.

병목인 80세 초과 REM 은 오히려 60.7 %에서 57.4 %로 나빠졌다. 나이를 사전 확률로
써서 눌러버린 것으로 읽힌다. 자세한 것은 `09-analysis.md` 참고.

**나이대별 가중치는 걸지 않았다.** 구간별 조각 수가 42k / 51k / 49k / 53k 로 이미
비슷해서 무게가 ±15 % 안에서만 움직인다. 고령은 데이터가 적어서 못 하는 것이 아니라
그냥 어렵다.

**나이대별로 모델을 따로 두는 방식도 접는다.** 나이 특징이 안 통했다는 것은 나이로
갈라도 새로 얻을 것이 없다는 뜻이고, 구간마다 피험자가 20명 남짓으로 줄어드는
위험만 남는다.

### 6. 짧은 구간 전용 처리

DS 오답의 절반이 3칸 이하 구간에서 나온다. 앞뒤 7.5분 평활이 한 칸짜리 DS 를 뭉갠다.
평활한 값과 평활하지 않은 값을 둘 다 넣으면 짧은 구간을 살릴 수 있다.

예상 0.5~2%p. 비용 중간. 특징 표를 다시 만들어야 한다.

## 순서 (2026-08-31 갱신)

1. **4번 REM 전용 특징** — 돌고 있다. 대역별 채널상관을 더했다
2. **1번 상태 전이** — 남은 후처리 중 유일하게 값어치가 있다. 학습을 다시 안 돌린다

2번 임계값, 3번 확률 보정, 5번 나이는 실측으로 값어치가 없어 접었다.

**모든 후처리는 학습 묶음에서만 정한다.** 평가 묶음을 보고 문턱이나 전이 표를 정하면
성능이 부풀려지고, 그건 조용히 틀린다.

**전이 표만 예외적으로 싸다.** 라벨만으로 만들어서 모델이 안 끼어들기 때문이다.
문턱과 보정은 예측이 필요한데, 저장해 둔 예측은 각 조각이 평가 대상이었을 때의 것뿐이라
정직하게 하려면 학습을 10번 더 돌려야 한다. 이것이 셋의 비용을 가른다.

## 그림 보완 계획

시스템 아키텍처와 모델 아키텍처는 나중에 다시 손본다.

- 세션 상태가 메모리에 쌓이는 구조를 그림에 반영할지
- 모델 그림에 성능 수치를 넣을지, 넣는다면 낡지 않게 유지하는 방법
- 저장 계층에 원신호를 켰을 때의 경로
- 서버를 여러 대로 늘렸을 때의 구성

## 아직 안 한 이해 작업

성능을 올리는 작업이 아니라 모델이 무엇을 보고 있는지 이해하는 작업이다.
사람별 성능 차이는 오차 분석에서 이미 다뤘고, 아래 둘이 남았다.



### 구간별 특징 시각화

수면 단계마다 특징 값이 어떻게 다른지 그림으로 본다.

- 단계별 특징 분포 (상자그림, 밀도)
- 하룻밤 동안 주요 특징이 어떻게 변하는지 시계열
- 단계가 바뀌는 지점에서 어떤 특징이 먼저 움직이는지
- 모델이 헷갈린 구간의 특징이 어떤 모습인지

### 잘라낸 각성 구간 다시 보기

지금은 잠든 구간 앞뒤만 남기고 나머지를 버린다. 버린 구간에도 쓸 것이 있는지 본다.

- 낮 각성과 밤 각성의 특징이 다른지
- 잠들기 직전 구간에서 수면 시작을 예측할 수 있는지
- 각성을 세분화하면(활동 중 / 누워서 / 졸림) 성능이 달라지는지
