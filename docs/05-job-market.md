## 2. 에이슬립(Asleep) — 도메인은 겹치는데 신호가 다릅니다

**핵심: EEG가 아니라 소리(오디오) 기반입니다.**

스마트폰 마이크로 수면 중 소리를 수집 → 호흡 변화 → 자율신경계 활동 → 수면 단계를 추정합니다.
자사 주장: *"수면 소리에는 스마트워치로 측정 가능한 생체신호보다 더 많은 수면 정보가 담겨 있다."*

| 항목 | 내용 |
|---|---|
| 제품 | AsleepTrack API (B2B SDK — 타사 앱에 수면 측정 탑재), SleepHub |
| 인증 | **식약처 2등급 의료기기** |
| 실적(자사 공개) | 특허 출원 74건, 논문 22편, 수면 데이터 220만+ 건 |
| 채용 | 원티드 검색 **0건**. 자사 채용페이지 404. **현재 공개 ML 포지션 확인 못 함** |
| 투자·규모 | 확인 못 함 (외부 DB 차단) |

**후보자 관점**: 이 회사의 핵심 문제가 **"저비용 신호로 PSG 수준의 수면 단계를 추정하는 것"** 입니다.
EEG로 PSG 라벨을 맞히는 경험은 그 문제의 **기준선(reference) 쪽**에 해당합니다.

지원한다면 스토리는 이렇게 됩니다 — *"EEG로 수면 단계 분류를 했고, 그 과정에서 PSG 라벨의 성질과 평가 설계의 함정을 파악했습니다. 같은 문제를 더 싼 신호로 푸는 것이 다음 단계라고 봅니다."*

## 6. 생체신호 vs 영상 — 영상이 훨씬 큽니다

원티드 검색 기준 "생체신호" ML 관련 2건(회사 1곳) vs "의료영상" + 루닛 16개 포지션 + 뷰노.
**조직 규모·포지션 수에서 영상 쪽이 확연히 큽니다.**

생체신호 쪽은 **절대 수가 적은 대신 회사 목록이 명확**합니다:
에이슬립, 휴이노(ECG 웨어러블), 스카이랩스(반지형 PPG), 웰트(불면증 DTx), 씩소시스템즈, 아슬론(시계열 생체신호 멀티모달), 병원 연구실.

> 적은 만큼 **EEG 논문 실적 보유자는 이 풀에서 희소성이 큽니다.**
> 다만 시장 전체를 노리려면 영상도 커버 가능함을 보이는 편이 안전합니다.
